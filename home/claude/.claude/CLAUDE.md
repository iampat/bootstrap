- This machine is managed by `~/workspace/iampat/bootstrap`. When installing a CLI tool or app,
  add it to that repo's `Brewfile` and run `brew bundle --file=~/workspace/iampat/bootstrap/Brewfile`
  instead of `brew install`.
- Clone git repos into `~/workspace/<owner>/<repo>`, e.g. `~/workspace/iampat/bootstrap`.
